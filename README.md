## 🜂 About

I work where **AI** meets **security**. I build tools that turn language models into dependable systems, and I care as much about how those systems fail as about how they work.

- 🧠 Fine-tuning, evaluation and control of LLMs
- 🛡️ Securing the AI stack: sanitising model input and output, auditing local model servers
- 🧰 Small, focused tools with clear docs, tests and honest benchmarks
- 🔬 Learning in public, one experiment at a time

## ⚗️ Featured projects

| Project | What it does |
|---|---|
| 🍺 [**Brainbrew**](https://github.com/Yog-Sotho/Brainbrew) | Turns your documents into training datasets by distilling a larger model, then fine-tunes a small one on them. Typed end to end, with a quality benchmark that runs nightly in CI. |
| 🧠 [**LLM-fine-tuner**](https://github.com/Yog-Sotho/LLM-fine-tuner) | A Gradio interface for fine-tuning language models without writing training code. |
| 🧼 [**LLM-Sanitizer-Pro**](https://github.com/Yog-Sotho/LLM-Sanitizer-Pro) | Cleans what goes into and comes out of language models. |
| 🔎 [**Ollama-Security-Auditor**](https://github.com/Yog-Sotho/Ollama-Security-Auditor) | Checks the security of Ollama deployments. |
| 🔐 [**Homomorphic-Encryption-Service**](https://github.com/Yog-Sotho/Homomorphic-Encryption-Service) | Computing on encrypted data. |
| 🌑 [**Nocturna-Trading-System**](https://github.com/Yog-Sotho/Nocturna-Trading-System) | An experimental ML and crypto trading system, built to avoid race conditions, blocking I/O and state loss in a crash. |
| 🕵️ [**Wash-Trade-Scanner**](https://github.com/Yog-Sotho/Wash-Trade-Scanner) | Looks for wash-trading patterns in market data. |

## 🧭 What I care about

```text
Honest measurement   A claim needs a benchmark, and a benchmark needs its caveats written down.
Secure by default    Secrets stay server-side. Private by default. Fail closed, not open.
Small and legible    Typed code, tests that mean something, docs a stranger can follow.
Free to run          If a tool needs a paid API to try it, I look for a free path first.
```
